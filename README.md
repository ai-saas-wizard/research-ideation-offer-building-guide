# Research, Ideation & Offer-Building Guide

Your course folder for *Research, Ideation & Offer-Building Guide*. An AI assistant (Claude Code or Codex) guides you through eight lessons, from something you have actually helped someone do to a researched customer and a tested coaching or consulting offer. Each lesson saves a short document that the next lessons build on.

## Get started

1. Install [Claude Code](https://claude.com/claude-code) or [Codex](https://openai.com/codex/).
2. Copy the course to your computer:

   ```sh
   git clone https://github.com/ai-saas-wizard/research-ideation-offer-building-guide.git
   ```

   No git? Click **Code → Download ZIP** on this page and unzip it.
3. Open the course folder in Claude Code or Codex.
4. Type: **Let's start the course.**

Then read [START-HERE.md](START-HERE.md) to see how the course works.

## Updating the course

Open your course folder and ask your assistant to update the course. Your own work stays on your computer and is never changed.
